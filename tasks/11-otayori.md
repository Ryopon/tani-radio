# 11 おたより機能

状態: 未着手

## 決まっていること

- ニックネーム必須で、誰でも送れる。
- NGワードをあらかじめ設定し、機械的に弾く。
- プロンプトインジェクションのような内容も弾く。
- 採用は1日2通まで。採用されなかったものは破棄する。
- 投稿の締切は、その日の生成開始時点。
- 採用済みのおたよりだけサイトで公開する。全件はClaude Code経由で確認する。
- 0通の日はコーナーを省き、ニュースを増やす。
- 住人のプロフィールは持たない。

## やること

- [ ] 投稿フォームの項目と文字数上限を決める
- [ ] 連投対策を決める（レート制限など）
- [ ] NGワードリストを作る
- [ ] インジェクション対策を決める（おたより本文を指示として扱わない台本生成の作り、判定手順）
- [ ] 採用の選び方を決める
- [ ] 採用済みおたよりの一覧ページを作る
- [ ] 全件を確認・削除する手順を用意する
- [ ] 投稿時の注意書きを書く（公開される、採用されないことがある等）

## 完了条件

投稿から番組での紹介、一覧への掲載までが通り、NGワードとインジェクションの試験投稿が弾かれる。
