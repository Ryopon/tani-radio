# 06 台本用のキャラクター定義

状態: 未着手

台本を生成するときにAIへ渡す、二人の人格定義を文書にする。

## 決まっていること

### ryopon

- 人間。ですます調、一人称は「わたし」。
- 進行役で、しゃべるのはryoponだけ。

### mui

- うさぎ。しゃべらないが表情は豊か。
- 斜に構えず、思ったことが素直に顔に出る。
- 「（いいね！）」「（よさそう！）」のように、脳内に直接語りかける形で伝える。
- 好き嫌いは特にない。異議があるときはジト目。

### 関係性

- お互いを仲の良い友達だと思っていて、信頼が厚い。
- 甘いだけではなく、おかしいと思ったことは素直に伝え合う。その傾向はmuiのほうが強い。

### 「谷」

- 番組上は記号として「谷」と呼ぶだけで、意味の説明はしない。

## やること

- [ ] ryoponの語彙、言い回し、言わせたくないことを決める
- [ ] muiの心の声の書き方ルールを決める（長さ、頻度、語尾）
- [ ] ryoponがmuiに触れる頻度の上限を決める（過剰にしない）
- [ ] 台本サンプルを数本作り、本人が違和感を確認する

## 完了条件

定義書があり、それを使って生成した台本を本人が「これで良い」と判断している。
