# 05 キャラクター素材の制作

状態: 未着手

## 決まっていること

- 素材はryopon本人が作る。形式はPNGのパーツ分割。
- muiはryoponの半分くらいの背丈で、丸みのあるシルエットのうさぎ。服や小物はなし。
- 表情は各キャラ5種（驚き、笑い、無表情、泣き、虚無）。muiはジト目も必要。
- AIは台本のタイムライン上で「表情、ポーズ、記号」を指定し、エンジンが動きを付ける。
- キャラをつつくと反応する。

## やること

- [ ] パーツ規格を決める（パーツの分け方、キャンバスサイズ、基準点、ファイル命名）
- [ ] 口パク用の口パーツの枚数を決める
- [ ] まばたき、揺れなど自動で付ける動きを決める
- [ ] つつかれたときの反応を決める
- [ ] [04](04-poses.md) で選んだポーズ分のパーツを描く
- [ ] 記号演出の素材を描く

## 完了条件

規格書と、規格どおりのPNG一式がそろい、エンジン上で全表情・全ポーズが表示できる。
