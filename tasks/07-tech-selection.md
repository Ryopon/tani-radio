# 07 技術選定

状態: 完了（構成は承認済み。残りは 14、15、16 に引き継ぎ）

## 制約

- 月1000円以内（Claude CodeとローカルLLMの費用は含めない）。
- スマホとPCの両方に対応する。
- 生成はローカルPCのClaude Codeスケジュールタスクで行い、生成後にデプロイする。
- 配信の非公開化などの管理操作はClaude Code経由で行う。管理画面は作らない。
- おたよりの投稿には受け付け用のバックエンドが要る。

## 構成案

Cloudflareの無料枠にまとめる。月額は0円の見込み（独自ドメインを取る場合のみ年1500円前後）。

| 役割 | 採用案 | 理由 |
|---|---|---|
| サイト本体（トップ、アーカイブ一覧、おたよりフォーム） | Cloudflare Workers の静的アセット | 静的アセットへのリクエストは無料・無制限 |
| 各回のバンドル（エンジン、音声、画像） | Cloudflare R2 に日付ごとのフォルダで保存し、Worker経由で配信 | 一度置いたら書き換えないので、過去回が変わらない要件に合う。転送料が無料 |
| おたよりの受け付けと保存 | 同じWorkerのAPI + Cloudflare D1 | 1つのWorkerで完結する |
| おたよりの連投・bot対策 | Cloudflare Turnstile + IP単位の回数制限 | 無料 |
| 公開・非公開の管理 | エピソード一覧のJSON（公開フラグ付き）をR2に置き、Claude Codeから書き換える | 管理画面が不要 |
| デプロイと管理操作 | ローカルから wrangler コマンド | Claude Codeのスケジュールタスクからそのまま実行できる |

### フロントエンド

| 項目 | 採用案 | 理由 |
|---|---|---|
| 言語・ビルド | TypeScript + Vite。UIフレームワークは使わない | エンジンを小さく保ち、各回に同梱しやすくする |
| 描画 | DOM + CSS変形（PNGパーツを重ねて動かす） | 字幕、リンク、タップ判定、その回だけの仕掛けを作りやすい。Canvasより無人生成で壊れにくい |
| 音声 | 声とBGMを1本にミックスしたMP3を、audio要素で再生する | スマホで画面を消しても再生が続く。シークが単純。audioの再生位置を全演出の時計にする |
| 演出の同期 | タイムラインJSON（時刻ごとのセリフ、表情、ポーズ、字幕、小物） | 目次ジャンプは再生位置を変えるだけで済む |

### 生成（ローカルPC）

| 項目 | 採用案 | 理由 |
|---|---|---|
| 音声合成 | VOICEVOXエンジンをローカルで起動し、HTTP経由で呼ぶ | 無料。音素ごとの時刻が取れるので口パクに使える。クレジット表記が必要で、声ごとの規約にも従う |
| 音声の結合・ミックス | ffmpeg | セリフごとの音声をつなぎ、BGMを重ねて1本にする |
| 小物の画像生成 | 未定（下の確認事項） | PCのGPU次第 |
| 小物の背景抜き | rembg などローカルの切り抜きツール | 無料 |

## 無料枠の確認結果（2026-11-12時点、Cloudflare公式ドキュメント）

- Workers: 1日10万リクエスト、1回あたりCPU 10ミリ秒。静的アセットへのリクエストは無料・無制限。
- D1: 保存5GB、1日あたり読み取り500万行・書き込み10万行。
- R2: 保存10GB、月あたり書き込み系100万回・読み取り系1000万回、転送料は無料。
- VOICEVOX: 商用・非商用とも利用可。クレジット表記が必要。音声ライブラリ（声）ごとの規約に従う。

## 容量の見積もり

- 1回あたり約5〜7MB（10分のMP3が約5MB、画像とエンジンで1〜2MB）。
- 1年で約2〜2.5GB。R2の無料枠10GBは4年ほどで埋まる。超過後は1GBあたり月0.015ドル程度（要確認）。
