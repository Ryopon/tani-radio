# 09 生成・配信パイプライン

状態: 未着手

## 決まっていること

- 毎朝8時ごろに配信する。生成は1日1回。
- Claude Codeのスケジュールタスクで生成し、生成後にデプロイして公開する。
- 完全無人で公開する。
- 朝にPCが起動していなかった場合は、その後のスケジュールタスクで生成する。
- それでも失敗した日は休止にする。
- 配信の非公開化はClaude Code経由で行う。

## やること

- [ ] 生成の手順を決める（情報収集、台本、音声、小物、ワンオフ実装、検証、バンドル、デプロイ）
- [ ] 8時に間に合わせるための開始時刻を決める
- [ ] 再試行のスケジュールと「休止」と判断する時刻を決める
- [ ] 同じ日に二重生成しない仕組みを決める
- [ ] 公開前の自動チェック項目を決める（再生できるか、尺、避けたい話題、画像の出典）
- [ ] 休止の日にサイトへ何を表示するか決める
- [ ] 非公開化と再生成の手順を用意する

## 完了条件

数日間、無人で生成から公開まで通り、失敗時に休止へ落ちることを確認している。
