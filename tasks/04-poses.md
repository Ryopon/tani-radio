# 04 ポーズの選定

状態: 未着手

## 決まっていること

- 表情はryopon・muiそれぞれ5種: 驚き、笑い、無表情（デフォルト）、泣き、虚無。
- muiが異議を唱えるときはジト目。
- 感嘆や疑問は記号的な演出（！、？など）も使う。
- ポーズは下の案からryopon本人が選ぶ。

## ポーズ案

### ryopon

- [ ] 基本（座り、手は机の上）
- [ ] 口に手を当てる（驚き、考え中）
- [ ] 指を立てる（解説、ポイント）
- [ ] 手を広げる（紹介、「こちらです」）
- [ ] 腕を組む（悩む）
- [ ] 頬杖をつく（しみじみ）
- [ ] 手を振る（OP・EDの挨拶）
- [ ] 紙を持つ（おたよりを読む）

### mui

- [ ] 基本（ちょこんと座る）
- [ ] 耳がぴんと立つ（驚き、興味）
- [ ] 耳が垂れる（しょんぼり）
- [ ] 前足を口元に当てる
- [ ] 身を乗り出す（わくわく）
- [ ] 首をかしげる（疑問）
- [ ] ぴょんと跳ねる（喜び）
- [ ] そっぽを向く（ジト目と組み合わせて異議）
- [ ] 丸くなる（虚無、眠い）

### 記号演出（キャラ共通）

- [ ] ！、？、汗、キラキラ、ハート、もやもや、電球、音符
