# 08 エピソード形式と再生エンジン

状態: 進行中（設計は承認済み。段階1・2を実装済み）

## 決まっていること

- 動画ではなく、往年のFlashのようなインタラクティブな番組にする。
- 構成要素: BGM、声、パーツで動くキャラ、背景、ニュースのテキスト・画像、小物、字幕。
- 各コーナーに目次があり、タップするとその位置へジャンプできる。
- キャラをつつける。小物をタップできる。元記事へ飛べる。
- 話題に合わせたワンオフのインタラクティブ実装を毎回入れられる。
- 各回は、その日のエンジンごと固めた自己完結バンドルにする。エンジンを更新しても過去回は変わらない。
- ワンオフ部分が壊れていたら、演出なしの通常版に自動で切り替えて配信する。
- 聞き流しでも情報が得られ、画面を見ると魅力が最大になる。
- 全体で約10分。

## 尺の配分

| パート | 尺 |
|---|---|
| OP（日替わりの軽い挨拶、今日がどういう日か） | 約30秒 |
| ニュース（2〜3本） | 約3分 |
| 雑学 | 約5分 |
| おたより（最大2通） | 1〜2分 |
| ED | 約30秒 |

おたよりが0通の日はコーナーを省き、その分ニュースを増やす。土日も同じ構成。

## 確認済みのこと（2026-11-12、サンプル回、開発サーバー上）

- PC幅とスマホ幅（375×812）の両方で表示が崩れず、横スクロールが出ない。
- 目次からのジャンプで、字幕・表情・ポーズ・現在のコーナー表示がその時刻の状態になる。
- キャラクターをつつくと一時的に表情が変わり、約1秒で台本の状態に戻る。
- 続きから再生、コーナー指定のリンク（`#news-2` など）が動く。
- コンソールエラーなし、型チェック通過。
