# 14 日替わりの背景と小物

状態: 未着手

## 決まっていること

- 季節や話題に合わせて、背景と小物を毎回変える。
- 小物は画像生成も使って表示し、タップなどのインタラクティブ要素を持たせる。
- ニュースや話題の内容から、その回だけのインタラクティブ表現を毎回考える。

- 背景は画面全体に広げる（2026-11-12）。舞台（1000×1000）より広い 2800×2800 で描き、舞台の左上が (900, 400) に来る。キャラクターが立つのは中央の舞台部分で、外側は画面の形によって見えたり見えなかったりする。見本は `npm run sample` で生成される `public/_sample/img/bg.svg`。
- 画面下部は操作盤やカードが重なるので、背景の下側（舞台より下）には見せたいものを描かない。
- 小物の画像生成はローカルで行う（RTX 2070 SUPER、VRAM 8GB）。SDXL系モデルを想定。

## やること

- [ ] VRAM 8GBで動く画像生成モデルを選び、1枚あたりの生成時間を測る

- [ ] 放送場所の基本設定を決める（未定。ラジオブース、部屋、谷の風景など）
- [ ] 背景の作り方を決める（本人が描いたベースに差分を重ねる、生成する、など）
- [ ] 生成した小物の絵柄を、本人のキャラ素材になじませる方法を決める
- [ ] 小物の標準的な反応を決める（タップで揺れる、説明が出る、音が鳴る）
- [ ] ワンオフ実装の範囲と制限を決める（[08](08-episode-engine.md) の差し込み口に合わせる）
- [ ] 生成画像のライセンスを確認する（使うモデルの利用条件）

## 完了条件

背景と小物が日替わりで生成され、絵柄の違和感がないことを本人が確認している。
