# 03 BGMの調達とライセンス確認

状態: 未着手

## 決まっていること

- フリー素材を使うか、ローカルで動く音楽生成モデルで毎回生成する。
- どちらの場合もライセンスを確認する。

## 注意点

- 生成用PCはVRAM 8GB。ローカルの音楽生成モデルは小さめのものに限られる。
- 音楽生成モデルには、非商用限定など生成物の利用に条件が付くものがある。採用前に必ず確認する。
- フリー素材は再配布禁止のものが多い。公開リポジトリには入れない（[15](15-repository-and-license.md)）。

## やること

- [ ] 方式を決める（固定のフリー素材、日替わりでフリー素材から選ぶ、ローカル生成）
- [ ] フリー素材の場合: 配布元の規約確認（公開サイトでの利用、加工、クレジット表記）
- [ ] ローカル生成の場合: モデル本体のライセンスと、生成物の利用条件を確認
- [ ] 必要な曲の種類を決める（OP、各コーナー、ED、ジングル）
- [ ] 声が聞き取りやすい音量バランスを決める

## 完了条件

BGMの方式と素材が決まり、ライセンス表記が [13](13-legal-notices.md) に反映されている。
